# Frontends

Insights uses a micro-frontend architecture, where each application has its own frontend bundle.
Frontend bundles from each application are created as a federated module (using [Module Federation](https://module-federation.io/), a [Webpack concept](https://webpack.js.org/concepts/module-federation/)).
Insights frontend bundles use the [PatternFly design system](https://www.patternfly.org/) and [React](https://react.dev/).

## Builds

Frontend assets are built into a scratch (or ubi-micro, the micro Universal Base Image) containers utilizing common build tools from [insights-frontend-builder-common](https://github.com/RedHatInsights/insights-frontend-builder-common/). The build script uses the build tool [`fec`](https://github.com/RedHatInsights/frontend-components/tree/master/packages/config#fec-node-scripts) from the Insights [frontend-components](https://github.com/RedHatInsights/frontend-components/) to build a federated module.

:::note
The [insights-frontend-builder-common](https://github.com/RedHatInsights/insights-frontend-builder-common/) is usually added to individual frontend Git repositories as a Git submodule at the path `./build-tools`.
:::

The assets are available inside the frontend containers at the path:

```
/srv/dist
```

:::tip
[OCI artifacts](https://oras.land/docs/concepts/artifact/) can be used instead of scratch containers. These can be managed by the [oras](https://oras.land/) tool.
:::

## Distribution and Serving

The frontend assets are distributed as content-only containers. Assets from these containers are copied to disk by Foreman Installer to the path:

```
/var/lib/foreman/public/assets/apps/<app_name>
```

The frontend artifacts on a Foreman instance are served as static files by [Apache httpd](https://httpd.apache.org) at the following location.

```
/assets/apps/<app_name>
```

## Context and Federation

The integration with the site is facilitated by [Scalprum](https://github.com/scalprum/scaffolding), a Module Federation-based framework that enables React applications to dynamically compose remote components and share hooks across a scalable, type-safe micro-frontend architecture.

The configuration for a federated module is read from the following URL path:

```
/assets/apps/<app_name>/fed-mods.json
```

Foreman, through the [RH Cloud plugin](https://github.com/theforeman/foreman_rh_cloud/), creates React entrypoint components for each subpage that wrap a federated Insights component. It provides a `ScalprumContext` that includes the essential information and APIs for Insights frontends.

The `ScalprumContext` provides these [Chrome APIs](https://github.com/RedHatInsights/frontend-components/blob/master/docs/chrome/chrome-api.md):

* [`auth.getUser()`](https://github.com/RedHatInsights/frontend-components/blob/master/docs/chrome/chrome-api.md#authgetuser)
* [`auth.getUserPermissions()`](https://github.com/RedHatInsights/frontend-components/blob/master/docs/chrome/chrome-api.md#getuserpermissions)

:::note
The Chrome APIs can be accessed via the useChrome hook from [frontend-components](https://github.com/RedHatInsights/frontend-components/tree/master/packages/components).

```
import useChrome from '@redhat-cloud-services/frontend-components/useChrome';
```

:::

See [ScalprumModule/ScalprumContext.js](https://github.com/theforeman/foreman_rh_cloud/blob/develop/webpack/common/ScalprumModule/ScalprumContext.js) and the entrypoints at [https://github.com/theforeman/foreman\_rh\_cloud/tree/develop/webpack](https://github.com/theforeman/foreman_rh_cloud/tree/develop/webpack).

## CSRF Protection

The Cross-Site Request Forgery token ([CSRF](https://en.wikipedia.org/wiki/Cross-site_request_forgery)) is required for every modifying request (e.g. `PATCH`, `POST`, `PUT`, `DELETE`). The token is generated by the Foreman backend and provided to the browser.

Frontend components that perform modifying requests must pass the CSRF token value in the `X-CSRF-Token` header. The token value can be read by the frontend from the document meta tag:

```
document.meta[name="csrf-token"]
```
